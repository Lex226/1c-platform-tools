# Session: ir-object-explorer

## Goal
- Собрать сырые находки об инструменте "Исследователь объектов" (`Ис()` / `Исследовать()`) подсистемы RDT1C для первой канонической страницы.

## Sources
- Официальная страница: https://devtool1c.ucoz.ru/index/issledovatel_obektov/0-25
- Официальная страница (функции для отладки): https://devtool1c.ucoz.ru/index/funkcii_dlja_otladki/0-33
- Репозиторий: https://github.com/tormozit/RDT1C
- Issue tracker (поиск "Исследователь объектов"): 18 совпадений, рассмотрены issues #42, #91, #92, #116, #186, #187, #218, #265, #303, #355, #356, #385, #523, #548, #550, #585, #661, #754

## Observed (externally-confirmed из официальной документации)
- Официальное описание инструмента: форма, представляющая свойства и методы переданного объекта в виде дерева, аналог диалога "Вычислить выражение" отладчика (источник: devtool1c.ucoz.ru).
- Программный вызов: `Исследовать(Объект, *Модально, *КакКоллекцию)` или короткая форма `Ис(Объект, *КакКоллекцию)` — предназначена для использования в точке останова.
- Отдельная функция `Ис(Объект = , КакКоллекцию = Ложь)` для отладки доступна и на сервере, и на клиенте; при вызове на сервере фактически выполняется только сохранение снимка объекта для отложенной отладки на клиенте через инструмент "Открыть объект для отладки".
- Есть форма-компаньон "Исследователь коллекций", открывается по двойному щелчку на ячейке "Количество элементов".
- Двойной клик на значении открывает специализированный инструмент, если он сопоставлен типу значения (например, редактор объекта БД для ссылочных объектов).

## Reproduced / issue-based findings (со статусами)

### 1. Разрыв цепочки "снимок на сервере → отложенная отладка на клиенте" для набора данных СКД
- Статус: **externally-confirmed** (issue закрыт как исправленный, есть точный стек вызовов и версии окружения).
- Платформа 8.3.26.1540, файловая БД, ERP 2.5.17.162, ИР Портативный 7.75.1p.
- При попытке открыть снимок объекта "МакетКомпоновки" (снятый через `От()`) в инструменте "Открыть объект для отладки" возникает ошибка `Значение не является значением объектного типа (НаборыДанных)`.
- Источник: https://github.com/tormozit/RDT1C/issues/754
- **Требует проверки**: актуальность для более новых версий RDT1C и платформы — issue закрыт, но не проверено на текущей 8.20.1.

### 2. Ошибка при просмотре коллекции "ДанныеКоллекцииФормы" через Исследователь коллекций
- Статус: **observed** (единичный репорт с подробным стеком, закрыт как исправленный).
- Платформа 8.3.21.1709, клиент-серверный режим, КА 2.4.13.187, расширение 7.01.1e.
- При передаче `ФормыКлиентскогоПриложения` (из "Структуры формы") в исследователь объектов и попытке открыть коллекцию, содержащую табличную часть со ссылочной колонкой + булево-колонкой, возникает `Ошибка при вызове метода контекста (ЗаписатьXML)` из-за `Несоответствие типов` при попытке сериализации.
- Источник: https://github.com/tormozit/RDT1C/issues/548

### 3. Ошибка раскрытия узла типа "Перечисление" в глобальном контексте
- Статус: **observed** (единичный репорт, закрыт).
- Платформа 8.3.20.1996, файловая БД, ERP 2.5.8.369, Портативный 6.63.1p.
- При команде "Глобальный контекст" и попытке раскрыть узел с типом "Перечисление" возникает ошибка `Операции сравнения на больше-меньше допустимы только для значений совпадающих примитивных типов`.
- Источник: https://github.com/tormozit/RDT1C/issues/355

### 4. Команда "Обновить" очищает объект вместо обновления значений
- Статус: **observed** (единичный репорт, закрыт как исправленный).
- Платформа 8.3.19.1229, клиент-серверный режим, ERP 2.5.6.261, расширение 6.07.1e.
- Команда "Командная панель \ Обновить" в диалоге просмотра выбранного объекта Исследователя объектов очищает содержимое вместо обновления.
- Источник: https://github.com/tormozit/RDT1C/issues/42
- **Discarded / superseded**: официальная страница описывает поведение кнопки "Обновить" как "перечитывает значения свойств" — то есть баг противоречит задокументированному поведению и был признан ошибкой, а не намеренным поведением.

### 5. Сериализация значения (XML/XDTO/XDTO+/Внутр/JSON) падает на пустом/неопределённом выборе
- Статус: **observed**, кластер из нескольких похожих репортов на платформе 8.2.19.130 (файловая БД, конфигурация "Конвертация данных" 2.1.8.2, Портативный 6.10.1p/6.11.1p).
- Ошибка `Значение не является значением объектного типа (Значение)` при нажатии кнопок XML/XDTO/XDTO+/Внутр/JSON без выбранной строки дерева значений.
- Источники: https://github.com/tormozit/RDT1C/issues/91, /92, /116
- Один из этих репортов (#92, ошибка XDTO на "Неопределено") был закрыт с меткой "отклонено" — то есть автор инструмента не счёл это дефектом, требующим исправления.
- **Discarded**: гипотеза "поведение сериализации одинаково для всех типов кнопок" — не подтверждена, т.к. один кейс отклонён, другие исправлены. Не переносить как единое утверждение.

### 6. Дублирование слов в подсказках/автодополнении
- Статус: **observed**, платформа 8.3.22.2283, файловая БД, расширение 7.19.1e.
- Источник: https://github.com/tormozit/RDT1C/issues/585 ("Исследователь объектов. Дублирование слов")
- Деталей воспроизведения недостаточно для reproduced — нужен собственный тест.

### 7. Итератор для значения не определён при вызове контекстной справки на строке ошибки вычисления выражения
- Статус: **observed**, платформа 8.3.20.1549, файловая БД, ERP 2.4.5.54, Портативный 6.23.1p.
- Источник: https://github.com/tormozit/RDT1C/issues/186

## Non-findings / explicitly rejected by maintainer
